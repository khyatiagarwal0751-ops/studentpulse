# studentpulse
Students often struggle to link daily study habits like attendance, revision, sleep and assignments to a clear improvement plan, and a score alone doesn’t say what to do next. StudentPulse brings an illustrative performance estimate, study suggestions, a weekly planner and focus tools into one browser-based dashboard.
# StudentPulse – Learning Intelligence Dashboard

StudentPulse is a browser-based student learning dashboard. It turns study habits into an illustrative performance estimate and suggested study actions.

## What it does
- Performance estimate out of 100 from study hours, attendance, previous exam score, assignments, sleep, class participation, weekly revision sessions and a target score
- Personalised next steps and a what-if comparison
- Weekly study planner with a checklist
- Focus Lab: focus timer, subject tracker, study notes and daily check-in
- Prediction history saved in the browser, with CSV export

## Tools used
HTML (index.html), hosted on Netlify
