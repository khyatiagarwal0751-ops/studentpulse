STUDENTPULSE WEBSITE — INTERACTIVE UPGRADE

Run locally:
1. Extract this ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
No Python, pip, Node.js, or internet connection is required.

Features:
- Responsive performance dashboard for desktop and mobile
- Interactive student profile inputs and transparent illustrative score estimate
- Personalised study suggestions and what-if scenario comparison
- Weekly study checklist saved in this browser
- Prediction history saved locally, with CSV export
- Dark mode
- NEW: Focus Lab with configurable focus/break timer
- NEW: Subject/project tracker with progress controls
- NEW: Auto-saved study notes
- NEW: Daily focus check-in and small-win reflection
- Completed focus sessions counter

Privacy:
The app is front-end only. Data is stored in this browser's localStorage and is not sent to a server. Clearing browser data may remove saved entries. The timer runs while the page remains open.

Important limitation:
The score uses a simple illustrative rule-based formula, not a trained or validated machine-learning model. Do not use it for grading, admissions, or consequential decisions.

To publish it, upload index.html to a static host such as Netlify, GitHub Pages, or Vercel. This project has no backend/database.
